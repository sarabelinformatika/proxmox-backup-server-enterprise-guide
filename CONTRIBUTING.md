# Contributing

Contributions that improve technical accuracy, recovery safety, or operational clarity are welcome.

1. Open an issue describing the proposed change.
2. Use a focused branch and small commits.
3. Do not include real credentials, hostnames, customer data, or production output.
4. Mark destructive commands and provide validation and rollback steps.
5. Run Markdown, YAML, shell syntax, link, and secret-pattern checks.
6. Submit a pull request with test evidence and affected PBS/PVE versions.

Documentation should distinguish vendor-supported behavior from local recommendations.
