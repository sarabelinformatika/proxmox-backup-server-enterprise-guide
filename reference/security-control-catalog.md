# Security control catalog

| Control | Minimum evidence |
|---|---|
| Dedicated backup identity | Named users and separated automation tokens |
| MFA for administrators | Enrollment and recovery procedure |
| Least privilege | Reviewed ACL and effective-permission export |
| Management isolation | Firewall rule and network diagram |
| Backup separation | PBS outside the protected cluster failure domain |
| Off-site copy | Successful pull sync and age monitoring |
| Integrity verification | Scheduled verification results |
| Recovery testing | Signed recovery-test records |
| Key protection | Offline escrow and recovery rehearsal |
| Capacity management | Forecast, thresholds, and expansion plan |
| Change control | Approved record and rollback evidence |
| Incident response | Tested credential-isolation and recovery runbook |
