# Security policy

## Reporting a vulnerability

Do not disclose exploitable weaknesses, credentials, customer names, hostnames, public IP addresses, encryption keys, or complete production configurations in a public issue.

Send a minimal report to **security@sarabelinformatika.hu** with the affected path, impact, safe reproduction steps, and a proposed mitigation if available. Remove secrets and customer-identifying data.

## Supported versions

Security corrections are maintained on the default branch and the latest release. Example files intentionally contain placeholders only.

## Operational warning

Commands in this repository are examples. Validate syntax and impact against the installed PBS release, local storage design, support subscription, and change process.
